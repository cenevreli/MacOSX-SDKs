# DT LMS Uygulaması

Basit bir tek sayfa Learning Management System (LMS) demosu.

## Özellikler
- Kurs seçimi
- Ders tamamlama işaretleme
- Kurs bazlı ilerleme yüzdesi
- İlerleme verisini `localStorage` ile saklama

## Çalıştırma
Herhangi bir statik sunucu ile açabilirsiniz.

Örnek:

```bash
python3 -m http.server 8080
```

Ardından `http://localhost:8080/dt-lms-app/` adresini ziyaret edin.
